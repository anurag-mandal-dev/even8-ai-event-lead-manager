# 2-minute demo script

1. Open the live app and point out the dashboard counters.
2. Click **Add lead** and create a sample lead with realistic notes.
3. Show that the lead appears in the pipeline.
4. Use the search box to find it and the status/event filters to narrow the list.
5. Edit the lead and change its follow-up status.
6. Click **Summarize** and explain that the browser calls the FastAPI endpoint, which calls the OpenAI Responses API server-side.
7. Click **Draft follow-up** and copy the generated message.
8. Open `/docs` on the API and show the documented REST endpoints.
9. Open GitHub and show the clean repository/README.
10. Finish by showing the deployed URL.
